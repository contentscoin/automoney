# ADR-0001 브라우저 자동화·Codex 실행은 유저 PC 데스크톱 에이전트에서 수행

- 상태: 채택
- 맥락: 스페이스(계정별 브라우저), 브라우저 고정, SNS 포스팅, Codex 구독 인증을 어디서 실행할지 결정 필요.
- 결정: Electron 데스크톱 에이전트가 브라우저·Codex·로컬 스케줄을 담당하고, Cloud는 MCP·정산·대시보드·잡 발급만 담당한다(blogautomcp 3-tier 구조 계승).
- 근거: Codex ChatGPT OAuth 토큰의 공식 사용 경로는 유저 로컬의 Codex CLI/SDK다. SNS 계정 안전상 유저 IP·디바이스에서 포스팅하는 것이 유리하다. 클라우드 브라우저는 비용·IP 평판·토큰 위임 문제가 있다.
- 결과: 유저 PC가 꺼져 있으면 예약이 지연될 수 있다(유효 창 정책으로 완화). 향후 유료 플랜에서 클라우드 브라우저 옵션을 추가할 수 있도록 잡 인터페이스는 실행 위치에 독립적으로 유지한다.
