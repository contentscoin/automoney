# ADR-0004 Threads·Instagram은 Meta API 우선, 브라우저 스페이스 폴백

- 상태: 채택
- 맥락: Meta API는 권한별 앱 리뷰(수 일~수 주)와 사업자 인증이 필요하고, 승인 전에는 테스터 계정만 사용 가능하다.
- 결정: 계정 단위 `auth_mode`를 두어 `META_API`가 가능하면 API로 발행하고, 미승인·토큰 만료·권한 부족 시 자동으로 `BROWSER`(스페이스)로 폴백한다. 두 경로는 동일한 `post.publish` 잡 인터페이스를 공유한다.
- 근거: 출시 일정이 Meta 리뷰에 종속되지 않도록 하면서, 장기적으로는 안정적인 API 경로로 이전한다.
- 결과: 발행 레시피와 API 어댑터를 모두 유지해야 한다. 릴스·캐러셀 등 미디어 규격 검증은 콘텐츠 엔진 단계에서 한 번만 수행한다.
