# 08. 콘텐츠 제작 워크플로

## 목적

상품을 발견한 뒤 링크와 콘텐츠가 서로 다른 화면에서 어긋나지 않도록, 최대 10개 상품을 한 캠페인 단위처럼 연속 처리합니다. 운영 기본값은 **검수 후 게시**이며 데모에서는 **무게시(dry-run)**까지만 수행합니다.

## 사용자 흐름

1. `/dashboard/workflow`에서 판매 중 상품을 최대 10개 선택합니다.
2. **데모 링크 만들기**로 선택 상품마다 링크를 발급합니다. `MOCK`/`DEMO` 링크에는 “실제 수익 추적 안 됨”을 표시합니다.
3. PC 앱 온라인 및 Codex 로그인 상태를 확인하고 채널을 선택합니다.
4. **AI 초안 만들기**로 상품별 `content.generate` 잡을 등록합니다. Codex 결과에 채널이 빠지면 해당 채널만 규칙 템플릿으로 보충합니다.
5. 상품별 콘텐츠에서 이미지·본문·광고 표기·금칙어·생성 출처를 확인하고 승인, 수정 또는 거절합니다.
6. 승인된 콘텐츠는 같은 상품의 활성 링크가 자동 선택된 게시 검토 화면으로 보냅니다. 서버가 상품 불일치와 채널·플랫폼 불일치를 다시 차단합니다.
7. 데모는 **실제로 게시하지 않기**를 켜고 작업을 승인하여 입력 단계까지만 확인합니다. 실제 게시 전에는 계정 소유자가 최종 문구와 링크를 확인해야 합니다.

## 데이터 경계

- 상품명·가격·카테고리·이미지·상세 URL처럼 등록된 카탈로그 값만 생성 근거로 사용합니다.
- “오늘출발”, “무료 교환”, “자체제작”, 순위, 최저가, 직접 착용 경험은 별도 근거 필드가 없으면 생성하지 않습니다.
- 아뜨랑스 상품 이미지와 상세 콘텐츠의 2차 가공·재게시 범위는 계약으로 확정하기 전 공개 캠페인에 사용하지 않습니다.
- 임시 링크의 `am_tc` 코드는 UI·클릭 로그 시연용입니다. 아뜨랑스가 인식하는 파트너 추적 코드가 아니므로 주문 귀속·수수료 정산 증빙으로 사용할 수 없습니다.

## 데모 완료 기준

- 실제 공개 상품 10개가 카탈로그에 등록되어 원본 URL로 열립니다.
- 선택한 10개 각각에 활성 데모 링크가 있고, 링크 종류가 화면에 표시됩니다.
- 선택 채널별 콘텐츠가 상품마다 생성되어 이미지와 함께 검수 가능합니다.
- 다른 상품의 링크, 비활성 링크, 다른 플랫폼 콘텐츠로 게시를 요청하면 서버가 거부합니다.
- 무게시 작업은 성공하되 외부 SNS에는 새 게시물이 생기지 않습니다.

## 실서비스 전 외부 선행 조건

- 아뜨랑스 파트너 API, 실제 tracking code, 주문 웹훅 및 월 정산 파일 규격 합의
- 상품 이미지·매거진 본문의 마케팅 재사용 권한 확인
- Meta 앱 사업자 인증·앱 리뷰 및 각 SNS 실제 계정 소크 테스트
- Windows/macOS 코드 서명과 운영 개인정보·정산 법무 검토
