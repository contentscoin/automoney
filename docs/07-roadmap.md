## 3. 오픈 이슈 (아뜨랑스·운영사 결정 필요)
1. 간접구매 유저 지급 여부와 요율.
2. 그레이드 구간(월 매출 기준)과 확정 시점.
3. 취소·반품 확정 대기 기간(예: 배송완료 + 7일).
4. 매거진 이미지·본문의 2차 가공 허용 범위.
5. 총판 모집 구조(초대 코드만 vs 승인제), 총판 수수료 상한.
6. 원천징수 처리 주체(운영사 지급 vs 아뜨랑스 직접 지급).

## 4. 검증 계획
- 정산 엔진: 단위 테스트(요율 조합·역분개·반올림·규칙 버전), 골든 데이터셋으로 월 정산 재현.
- 계약 테스트: blogautomcp 방식 `verify-*` 스크립트 — 웹훅 서명, MCP 툴 스키마, 잡 결과 봉투, 권한별 응답 필드 화이트리스트(간접구매 누출 0건).
- E2E: 링크 발급 → 클릭 → 테스트 주문 웹훅 → 대시보드 → 월 마감 → 명세서. 스페이스 3계정 7일 예약 포스팅. 텔레그램 `/post` → 승인 → 게시 URL 검증. MCP 클라이언트에서 동일 흐름.
- 보안: 개인정보 필드 암호화 확인, 감사로그, OAuth PKCE·스코프 테스트, 디바이스 재발급 시 토큰·잡 회수.
